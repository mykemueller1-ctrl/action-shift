# Action Shift — Grok Bot templates

Six recipes from this desk. The quality bar is **Two Invoice Catcher**: one job, paste the evidence, label every dollar VERIFIED / ESTIMATED / MISSING, never invent, name the next action, a human taps send.

Live listing to match: https://grokbots.best/bots/two-invoice-catcher

This folder cannot publish to grok.com. You paste. You hit Share as template.

## Publish one bot (2 minutes)

1. Open grok.com → New → Create new agent.
2. Paste the matching `*.md` file as the first message.
3. Bot actions → Edit Profile. Name + description from `roster.json`.
4. Bot actions → Share as template → Public → copy the x.ai link.
5. Do not connect the Community Tap house inbox to a stranger’s copy. They use their own files.
